## Description (≤ 500)

Concrete Contractors Estimator does the take-off before a pour: cubic yards with waste for slabs, driveways, patios, footings, columns and steps, the ready-mix order quantity, 80/60/40 lb bag counts, rebar or mesh, a rough installed cost and a pour-day plan from the forecast high. Free and open source: Android app, web calculator, Docker image, and libraries for JS, Python, Rust, Dart, .NET, Ruby and PHP.

## First comment

Hi Product Hunt! We pour driveways, patios and pool decks in the desert, where a 110 F afternoon can ruin a slab. We kept doing the same math on the back of receipts (yards, bags, rebar sticks, when to start the pour) so we turned it into one small, offline tool and open-sourced the formulas. Every port returns the same numbers. Feedback on the cost ranges and pour tips is very welcome.
