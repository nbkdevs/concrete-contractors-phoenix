## Summary

A warm desert sunset theme: violet sky, glowing sun, layered mesas and saguaro silhouettes.

## Description

Bring the calm of a desert evening to every new tab. Saguaro Sunset paints the new tab page with a violet-to-gold sky, a low glowing sun, layered red mesas and tall saguaro cacti in silhouette. The frame and toolbar use deep dusk purples with warm sand-coloured text and icons, so tabs stay easy to read in light and dark rooms.

- Hand-built 2560 x 1440 new tab artwork, sharp on large and high-DPI screens
- Dusk purple frame and toolbar, warm text and icon colours
- Image anchored to the bottom so the horizon stays in view on any window size
- No permissions, no data collection

Install it, open a new tab and enjoy the sunset.
