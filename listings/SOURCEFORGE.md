## Full description (plain text)

```
Concrete Contractors Estimator does the take-off concrete contractors run before every pour. Enter the dimensions of a slab, driveway, patio, continuous footing, round column or set of steps and get:

- Volume in cubic feet and cubic yards with a waste allowance
- The ready-mix order rounded up to the next 1/4 yard, with a bags-vs-truck recommendation
- 80 lb, 60 lb and 40 lb premix bag counts
- A rebar grid (bar count, linear feet, 20 ft sticks with 10% for laps) or wire mesh sheets
- A rough installed cost range for broom, colored, exposed aggregate or stamped finishes, with optional tear-out
- Hot-weather pour advice (start time, curing schedule, monsoon tips) for desert climates

Downloads:
- concrete-contractors-estimator-web-1.0.0.zip: offline web calculator. Unzip and open index.html in any browser. No install, no network calls, no tracking.
- concrete-contractors-estimator-1.0.0.vsix: VS Code extension with an estimator panel and a command that inserts the result as a Markdown table.

The same estimator is available as libraries for JavaScript (npm concrete-contractors-estimator), Python, Rust, Dart, .NET, Ruby and PHP.

Homepage: https://concretecontractorsphoenix.net/
Source code: https://github.com/nbkdevs/concrete-contractors-phoenix
License: MIT
```
